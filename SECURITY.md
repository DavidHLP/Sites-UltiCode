# Security policy

## Scope and maintenance

This policy covers **DavidHLP/Sites-UltiCode**: the public website, rendering, login integration, enquiries, ownership controls and analytics. The website is a separate application from the UltiCode online judge. Report product vulnerabilities to the [UltiCode product's private reporting channel](https://github.com/DavidHLP/UltiCode/security/advisories/new).

The website is maintained on `main`; there are no separately supported versioned website releases. Fixes target current `main` and require publication before reaching the hosted website. Include the affected URL, observation date and source revision when known so maintainers can distinguish deployed behavior from source changes.

## Report privately

Use [Report a vulnerability](https://github.com/DavidHLP/Sites-UltiCode/security/advisories/new) to contact the website repository owner privately through GitHub. Private vulnerability reporting is enabled for this repository. GitHub sign-in may be required; opening the form sends nothing until you submit it.

Include a concise summary, affected component/revision, expected and actual behavior, minimal safe reproduction and potential impact. Redact credentials, cookies, personal records and unrelated private material. Reproduce with accounts and data you control; avoid accessing other people's enquiries or disrupting the hosted service.

Do not post exploit details in public Issues, pull requests or the ordinary website enquiry form. If GitHub does not offer the private reporting action, check the [current repository security page](https://github.com/DavidHLP/Sites-UltiCode/security) and [GitHub's reporting guidance](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately). You may open a public Issue asking only for a confidential contact route, without vulnerability details, while the private route is restored.

## Handling and disclosure

The repository owner reviews reports, requests clarification and coordinates fixes and disclosure in the private advisory. There is no promised acknowledgement or remediation deadline, staffed emergency response or bounty program. Keep details private while coordinating an appropriate disclosure with the maintainer. Incidents in a self-hosted product installation also require that installation's operator.
